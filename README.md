# ⏱️ Cronômetro Web

Um projeto simples, responsivo e funcional de um **Cronômetro Web** desenvolvido com HTML5, CSS3 e JavaScript Vanilla. O projeto permite iniciar, pausar, zerar e registrar voltas (laps) de forma precisa e intuitiva.

---

## 🚀 Funcionalidades

- **Iniciar / Pausar:** Controle simples para iniciar e pausar a contagem de tempo.
- **Zerar (Reset):** Reinicia o cronômetro para o estado inicial (`00:00:00`).
- **Registrar Voltas (Laps):** Salva marcações de tempo intermediárias em uma lista organizada.
- **Interface Responsiva:** Design otimizado para navegação em dispositivos móveis e desktops.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização, layout flexível e design responsivo.
- **JavaScript (ES6+):** Manipulação do DOM e lógica de contagem de tempo utilizando `setInterval` / `Date`.
